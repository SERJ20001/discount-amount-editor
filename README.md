# Настройка скидки

Интерактивный прототип: линейная шкала 50–1500 ₽, ручной ввод суммы, цифровая клавиатура и товары с минимальной скидкой.

Фон экрана — #606060. Состояние хранится в памяти вкладки. Прототип использует демонстрационные данные.

Для локального запуска: `python3 -m http.server 8794`, затем открыть http://localhost:8794/.

HTML, CSS, JavaScript, изображения и шрифты находятся в этом репозитории. Сборщик не требуется.
